

### Q, V, A

**Value Function** - $V(s)$
- Dependent on state only
- The Value function helps us understand which states are most desirable overall
- Expected reward $E[r]$ the agent will get starting from following a specific optimal policy $\pi$ from state $S_{0} \to S_{\tau}$
- ***V-function: Doesn't directly tell you which action to take***

**Q Function** - $Q(s,a)$
* Function dependent on state and action 
* represents the expected ($E$) cumulative reward an agent can obtain by taking a specific action $a_t | \pi$ in a particular state $s_t$ and then following a specific policy
* It answers the question: "How good is it to take this action in a given state?"
*  ***Q-function: Can be used to directly select the best action in a given state (greedy, $\epsilon$-greedy, random action sampling...)***

**Advantage** - $A(s, a)$
* Advantage is function of Q and V
* Advantage measures the relative value of an action compared to the average
* It is a way to prioritize actions that lead to higher rewards than the expected reward for that state.

**Expectation** - $E[X]$
-  ***In a word***: "probability weighted average value"
- Expectation gives you a sense of what to expect on average from a random variable or a stochastic process.
- The expected value of $X$ (a random variable) summed over its probability density function $p(x)$ 
- $E[X] = \sum_{x=0}^{i} [x * p(x)]$
- e.g. for blackjack the $E[🃏]$ for a player being dealt cards... 
	- $E[🃏]$ = expected hand value = 16.7 
	- = $\sum$ 🃏 * p( random_draw )

#### Expectation in RL

**Q-function: Expected reward (given current state and action-space)
- On average what is the reward ($r$) of taking an action from and action-space in in current state in state ($s_t$)
- immediate reward Q-value :  $Q = \mathbb{E}_{\pi} [r(s', a') | s_t, a_t]$   
- finite-horizon Q-function :  $Q^\pi(s_t, a_t) = \sum_{τ=t}^T E_\pi[r(s_\tau, a_\tau) | s_t, a_t]$
- infinite-horizon Q-function :  $Q^\pi(s, a) = \mathbb{E}_\pi [\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} | s_t = s, a_t = a]$

**Value**: Expected Q-Value (given current state)
- On average that is the Q-function value of actions sampled from the current behavior-policy ($a_t \sim \pi_{theta}$) in state ($s_t$)
- $V(s_t) = E_{a_t \sim \pi(a_t|s_t)} [Q^{\pi}(s, a) | s_t, a_t]$

**Q-Learning Target** - $y$
- A crucial component of the Q-learning algorithm
- It is a specific application of bootstrapping to estimate the expected future reward in the context of Q-learning
- It represents the expected future reward from a given state-action pair.

$y \approx r(s, a)+V(s_{t+1})$ = immediate reward + $\mathbb{E}$(future reward)

Breakdown:
- **`y`:** This is the target value we're trying to estimate. It's the expected future reward.
- **`r(s, a)`:** This is the immediate reward received after taking action `a` in state `s`.
- **`V(s_{t+1})`:** This is the estimated value of the next state `s_{t+1}`. It represents the expected future reward starting from that state.

$y = r(s_t, a_t) + \gamma * max (Q(s_{t+1}, a_{t+1}))$

# Jargon Glossary

#### On-Policy vs. Off-Policy Learning

**On-Policy Learning (First Hand Experience)**

- **Definition:** The agent learns a policy that is used to generate its own experiences.
- **Process:** The agent interacts with the environment, collects data, and updates its policy based on that data.
- **Example:**
    - **Car Driving:** The agent learns to drive by steering the car itself. It collects data on its actions and their consequences, and updates its driving policy accordingly.

**Off-Policy Learning (Observational)**

- **Definition:** The agent learns a policy based on data collected from a different policy (or expert).
- **Process:** The agent observes data generated by another policy (often a random or exploratory policy) and learns a new policy based on that data.
- **Example:**
    - **Car Driving:** Tesla FSD (Fully Self-Driving) learning from MILLIONS of driver hours
    - **Game Playing:** The agent learns to play a game by watching human players or other agents play. It observes their actions and their outcomes, and learns a policy that mimics their success.

#### Online vs. Offline Learning

**Online Learning:**

- **Definition:** The agent learns incrementally, updating its policy as it receives new data.
- **Process:** The agent interacts with the environment and updates its policy immediately based on the new experience.
	- Iterative process `for loop`
- **Example:**
    - **Car Driving:** The agent learns to drive by steering the car and updating its policy in real time based on the results of its actions.

```python
# Q-learning algorithm pseudo code

while not game_over: 
	s = current_state 
	a = update_policy(s, a, r, s_next) 
	# Take action in the environment 
	s_next, r, done = environment.step(a) 
	
	if done: 
		# Game over, reset the environment 
		environment.reset()
```

**Offline Learning:**

- **Definition:** The agent learns from a fixed dataset of experiences.
- **Process:** 
	- The agent is trained on a dataset of pre-collected experiences, without interacting with the environment during training.
	- ***Replay buffers*** are used to store data collected from a different policy, allowing the agent to leverage other collected experiences
- **Example:**
    - **Game Playing:** The agent learns to play a game by training on a large dataset of game replays.****

**Replay Buffers**

- **Definition:** A data structure that stores past experiences.
- $D = [a_i, s_i, r_i, s'_i]$

#### Bootstrapping

"learning from educated guesses"

- **Intuition:** Using your current estimates of values (Q-values or V-values) to improve those estimates. 
- **Purpose:** It allows us to learn from experience without having to wait for the entire future to unfold (full episode from $t=0 \to \tau$)
- Instead of sum of future rewards ($\sum_{0}^{\tau}R_{t+1}$), "bootstrapping" uses value-estimate + only the immediate reward at current time $t$


$y \approx r(s, a)+V(s_{t+1})$ = immediate reward + $\mathbb{E}$(future reward)

**Bellman Equation:** A recursive equation that relates the value of a state to the immediate reward and the discounted value of the next state.

Bellman Equation (for V-values)
$V(s_t) = R_t + γ * V_{est.}(s_{t+1})$
