# Offline RL Advanced Topics

learning on static data sets, not using a hi-fidelity simulation model


## Data driven RL

Loop
1. COLLECT learn from big static data
2. TRAIN: train on data
3. DEPLOY: generate more data (from agent operating in environment post training)

### What we've coved so far

**On Policy RL**
- single policy \pi drives data gen and training

**Off Pol RL**
- policy \pi trained on data generated by other policies
- using buffer D
- more sample efficient

**Offline RL** (aka fully off policy RL)
- data collection divorces from agent training
- EVEN more sample efficient
- Use cases
	- difficult to sim
	- HIPPA
	- Data from similar domains


### How Offline differs from Imitation Learning

a. Provide optimal behaviors
b. Combine good behavior on different scales 
c. Generalization: provide data the can be extrapolated upon


#### The "drive off the road" problem

Question: how to get an agent that knows driving of the road if that action is not in the dataset 
- counterfactuals?

Result: Agent "drives off there road" if Offline RL is naïvely applied. The agent fails when it takes actions outside of distribution (OOD) even though it thinks its doing well (high Q value)

Reason: Bellman error for OOD actions tends to be high and accumulates over time
